## Upwork Title

AI Workflow Assistant for Client Requests

## Role

AI Workflow Developer

## Description To Paste

Sample project: I built an AI-style workflow assistant that helps small teams triage inbound client requests. The app classifies message intent, estimates priority and SLA, drafts a client reply, and generates an automation handoff checklist. It includes an inbound queue, filters, a new-message testing form, JSON exports, and a responsive dashboard. The public demo uses a local analysis engine so it runs without API keys, and the same structure can be connected to an LLM API, CRM, ticketing system, spreadsheet, or email inbox.
