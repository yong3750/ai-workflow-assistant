## Short Description

A sample AI-style operations assistant that classifies inbound client messages, estimates priority, drafts replies, and generates automation handoff steps.

## Long Description

This is a sample project built to demonstrate how I can design and implement AI-assisted workflow tools for small teams.

The app turns messy inbound requests into structured output: intent classification, priority level, SLA estimate, client reply draft, and an automation plan. It includes an inbound queue, filters, a new-message testing form, JSON export, and a responsive interface for desktop and mobile review.

The public demo uses a local deterministic analysis engine so it can run without API keys. In a real client project, this interface could be connected to an LLM API, email inbox, CRM, ticketing system, spreadsheet, or database.

Key features:
- Inbound request queue
- AI-style request classification
- Priority and SLA estimate
- Reply draft generation
- Automation checklist generation
- Queue filters
- JSON handoff export
- Responsive UI

Built with HTML, CSS, and JavaScript.
